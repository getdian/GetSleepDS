小程序与订阅消息

「结束入睡」到点提醒使用的订阅消息模板。保存后立即生效，不需要重启容器。

通知

模板 ID 为空时，小程序里点「到点提醒我结束」会回退为“加入手机日历”。

模板字段映射

按模板详情里的「关键词」填写。例：模板是「提醒时间 time1 + 超时惩罚 thing2」，就填 thing2 与 time1；模板是「提醒事项 thing1 + 提醒时间 time2」，保持默认即可。字段名对不上时微信返回 47003。

去哪里拿模板 ID

  1. 用小程序管理员扫码登录 微信公众平台（mp.weixin.qq.com）。
  2. 左侧 功能 → 订阅消息 → 「公共模板库」搜索“睡眠 / 提醒 / 打卡”，选用一个含 提醒事项（thing1）与 提醒时间（time2）两个字段的模板；「我的模板」里已有则直接用。
  3. 进入模板详情，复制 模板 ID（43 位字母/数字/下划线/短横线），粘贴到上面。
  4. 模板字段必须与发送的 thing1、time2 对得上，否则微信返回 47003；字段名以模板详情里的「关键词」为准。
  5. 本产品使用一次性订阅：用户每点一次「到点提醒我结束」授权一次，只能收到一条，符合平台规则。

运行环境（只读）

AppID / AppSecret 属于密钥，只能在服务器 .env 配置并重启容器；后台只显示是否就绪，不保存、不回显。AppID 与 AppSecret 在公众平台「开发 → 开发管理 → 开发设置」查看（Secret 只显示一次，重置后旧值立即失效）。
