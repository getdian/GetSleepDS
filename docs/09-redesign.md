# 睡点 · 新版信息架构与视觉系统

- 日期：2026-10-18（2026-10-19 融合 audio-dock / 3D 翻转 / A-B-C 态 / 横向热力图，并按参考图收敛视觉）
- 范围：小程序 3 个 tab + audio-dock 声音抽屉
- 目标：把「睡眠计算器」做成一打开就能用、且视觉上不像模板工具的产品

> 以下是 2026-10-19 微信开发者工具真实截图（AppID `wx378b0a7437d60998`），不是静态效果图。计算器已去掉内层轮盘面板、中央高亮带、紫色文字光晕与多余描边；顶栏改为全宽透明 + 通栏灵动岛。

## 1. 信息架构

| Tab | 页面 | 职责 |
|---|---|---|
| 计算器 | `pages/index/index` | 按起床倒推入睡、按入睡计算起床 |
| 入睡 | `pages/sleep/sleep` | 入睡/起床打卡、近 7 天、audio-dock 入口 |
| 统计 | `pages/stats/stats` | 周均值、横向热力图、事实回顾、海报、同步/清除 |
| 环境音 | `components/audio-dock` | 入睡页悬浮钮 + 底部抽屉，不是独立页面 |

打卡不再放在计算器页。计算器只回答“几点睡/几点起”，入睡页只负责记录，统计只负责回顾——三个 tab 各自闭环。

## 2. 计算器

### 2.1 交互

- **单卡双面**，默认「我想几点醒」；卡顶是一个轻量 pill + `↔`，点击切换「我想几点睡」，不做传统 segmented control。
- 正面：12h 时间轮 + 共享入睡耗时 `5/10/15/20/30 分钟`（默认 15，仅当前值带小标签底）+ 动态主按钮（`计算我的睡点` / `计算我的起床时间`）。
- 点击后只让计算卡做真正的 3D 翻转（`perspective: 1600rpx` + `preserve-3d` + `backface-visibility`），Hero、脚注、底栏不翻转。
- 结果面：第一推荐大号 + 左侧紫色竖条，其余两行弱化；「重新选择」翻回正面；「换成我想几点睡/醒」切换方向并翻回，不刷新页面。
- 计算器只记忆上次的起床时间；入睡时间每次默认跟随真实当前时间，入睡耗时默认 15 分（本次会话内可调整）。
- 入睡模式默认取当前时间（精确到分钟），点“用现在”可即时回到当下；切换模式不会让“预计入睡耗时”行上下跳动。
- 起床模式在时间轮下显示「今天/明天 上午/下午 HH:MM 起床」，与倒推算法共用 `nextWakeAt`；结果时间前缀改用「凌晨/早晨/上午/中午/下午/傍晚/晚上」，不再用「今天/明天」。
- Hero 背景图：后台配置多张/分类/默认图；默认图免费并静默缓存，用户更换需看激励视频，到期回退默认。

### 2.2 算法

- 起床倒推：`W - B - 90 × n`，`n ∈ {5,4,3}`；目标起床取下一次该时刻。
- 入睡推起床：`S + B + 90 × n`，`n ∈ {5,4,3}`；选中的时间已过去超过 30 分钟按次日处理。
- 三个入睡时刻全部已过时，结果卡改为“现在睡还能睡 X”，并列出三个已过时刻。
- 纯函数在 `miniprogram/utils/plan.js`，Node 单测覆盖（`tests/plan.test.js`）。

### 2.3 文案

- 结果只陈述时间与周期，不出现“建议、应该、睡眠质量”。
- 底部固定一句：“每个完整周期约 90 分钟。这里只做时间倒推，不做睡眠评价。”

## 3. 视觉系统

Token 全部写在 `miniprogram/app.wxss` 的 `page` 上，页面与组件只引用变量：

- 底色 `#080B14`，卡片实底 `#141B2D`，毛玻璃 `rgba(20,27,45,.65)`。
- 主色 `#818CF8`，深色 `#4F46E5`，月金 `#FDE68A`，薄荷 `#2DD4BF`。
- 文字：月华白 `#F8FAFC`、正文 `#E2E8F0`、次要 `#94A3B8`、弱化 `#64748B`。
- 圆角 16/24/32/48rpx；间距 8/16/24/32/48rpx。
- 动效：`--ease-spring` 弹性按压、`--ease-gentle` 渐显、`flip-in` 结果翻转。
- 字体：主标题/问题用系统 sans（600），只有“晚安/愿今夜好眠”等诗意文案用宋体。

### 3.1 通栏顶部（自定义导航）

- `app.json` 设置 `navigationStyle: "custom"`，去掉固定原生导航条。
- `components/top-bar` 读取状态栏与胶囊位置，铺一条**透明通栏顶部**；胶囊左侧是一整条玻璃“灵动岛”（不是小胶囊），从左侧安全边距延伸到胶囊前。
- 顶栏本身完全透明，只有 island 有半透玻璃；`position: fixed` 悬浮，页面滚动时内容从岛下方穿过，没有整块固定背景。
- 页面用 `topbar-spacer` 预留高度，避免第一屏被盖住。

### 3.2 氛围背景

`components/ambient` 固定全屏：

- 一层深空径向渐变 + 一层极慢（12s）呼吸月晕，不再叠星轨/星点/多重光斑。
- 全部 `pointer-events: none`，透明度很低；低端机少一层动画，视觉更干净。
- 页面内容统一包在 `.page`（`z-index: 1`）里。

### 3.3 玻璃卡片

`.sleep-glass-card`：实底 + 半透 + 1rpx 月影描边 + `0 12rpx 36rpx rgba(0,0,0,.26)` 轻阴影。
`backdrop-filter` 不支持时，实底 `--bg-night-surface` 仍可读。去掉了顶部高光和选中态紫色描边，减少“每条都发光”的噪声。

### 3.4 时间轮

`components/time-wheel` 自绘 12 小时循环轮：

- 主区两列：时 01–12 / 分 00–55；右侧窄列只放“上午/下午”文字切换，选中项是柔和底色，不再画两个方块。
- 对外仍用 24 小时 `"HH:MM"`；上午 12 点 = 00:00，下午 12 点 = 12:00。
- 时、分各渲染 3 个周期，滚到首尾周期后无感回到中间周期，23 点/55 分不再是终点；已在开发者工具用 `23:55` 和边界 `settle` 验证。
- 未选中约 45% 透明蓝灰、选中月华白 78rpx；中央是极轻全宽光带，选中数字保持白色。上午/下午是分段选择，点当前项不会改变时间。
- 所有颜色有显式 fallback；使用 `scroll-view` + 130ms 防抖吸附，滚动结束对齐最近行；计算前调用 `flush()` 强制落定，避免旧值计算。

## 4. 入睡页

- 顶部日期 + “我几点睡的”。
- 三态：A 未记录 / B 睡梦中 / C 已完成。
  - A：月相大圆钮“入睡”，点击全屏熄灯并显示“晚安”。
  - B：圆钮“记录起床”，下方提供“点错了？撤销本次入睡”（只清会话，不产生记录）。
  - C：圆钮收起，改为入睡/起床/在床时长三项汇总；可撤销。
- 最近 7 天圆点条：已完成为实心分级，进行中为空心光环，今天有外圈高亮。
- 右下角 audio-dock 悬浮钮；播放中变成底部迷你播放器（标题、剩余定时、暂停/展开）。
- 切换 tab、收起抽屉都不中断音频；只有播放条关闭或定时到点才停止。

## 5. 音频与定时

- `components/audio-dock`：悬浮钮 → 迷你播放器 → 底部玻璃抽屉（解锁条、搜索、分类、列表、定时、缓存）。
- 继续使用 `BackgroundAudioManager`（不是 `InnerAudioContext`），锁屏/切 tab 可播；抽屉 `detached` 只解绑监听。
- 定时器是 `utils/audio-timer.js` 模块单例，跨页面存活；到点停止并清除迷你播放器。
- 音频播放时写入 `lastTrackTitle / lastTrackActive`，回到入睡页可恢复迷你播放器状态。
- 跨页控制：声音入口仍在入睡页；开始播放后，首页/统计页出现 `now-playing` 迷你条，可暂停/继续/停止或点回入睡页。
- 解锁：广告与缓存并行，看完广告通常直接本地秒播；缓存可在抽屉里查看占用并清理。
- 收藏：列表右侧星标，本地持久化；分类栏的“收藏”可直接播放收藏列表（不参与云同步）。

### 5.1 统计页

- 近 3 个月横向热力图（7 行、周一对齐、月份标签、今日圈、仅入睡空心格）；起点为 3 个月前的 1 号（当前 10 月即 7 月 1 日），末尾约 3 周为未来板位（虚线 + 淡填充），点击提示“还没到”。范围不可切换，标题右侧只留一行“近 3 个月”标注；底部信息行是“共 N 天完整记录”+ 圆形分享钮 + 淡紫胶囊“生成月度海报”。
- 本周均值、连续天数、事实回顾；云备份开关 + 手动同步（默认关闭）。
- “生成月度海报”保存到相册，并作为分享卡片图；旁边有独立的页内转发入口。
- 广告位观测：展示位加载成功/失败上报 `ad_show` / `ad_error`，后台概览看填充率与分槽数据。
- “清除数据”：未开启云备份时本地立即清除，并保留云端副本重试入口；已开启时先调 `POST /api/records/erase` 成功后再清本地，失败可只清本机。清除会同时清理解锁、收藏、计算偏好、缓存，弹窗逐项说明。
- 关闭云备份后可在同一区域单独“删除云端副本（保留本机）”，走 `cloudOnly`，不写 erasure 水位。

## 6. 兼容与降级

- `backdrop-filter`、flex `gap` 在低端安卓/旧 iOS 上可能降级；实底、纯渐变、相邻间距仍成立。
- 时间轮不再使用原生 `picker-view`，因此不存在原生白色 `mask-style` 遮罩；选中态完全由自绘 class 保证。
- 熄灯动画是透明度过渡，不做位移，低端机也不掉帧。
