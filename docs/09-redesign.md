# 睡点 · 新版信息架构与视觉系统

- 日期：2026-10-18（2026-10-19 融合 GetSleepStep 的 audio-dock / 3D 翻转 / A-B-C 态 / 横向热力图）
- 范围：小程序 3 个 tab + audio-dock 声音抽屉
- 目标：把「睡眠计算器」做成一打开就能用、且视觉上不像模板工具的产品

> 下图是 2026-10-18 的第一版静态设计预览（计算器正脸 + 入睡页），**不是小程序截图**，也未包含本轮新增的 audio-dock、3D 结果背脸、横向热力图与海报；真实渲染需在微信开发者工具中验收。

## 1. 信息架构

| Tab | 页面 | 职责 |
|---|---|---|
| 计算器 | `pages/index/index` | 按起床倒推入睡、按入睡计算起床 |
| 入睡 | `pages/sleep/sleep` | 入睡/起床打卡、近 7 天、audio-dock 入口 |
| 统计 | `pages/stats/stats` | 周均值、横向热力图、事实回顾、海报、同步/清除 |
| 环境音 | `components/audio-dock` | 入睡页悬浮钮 + 底部抽屉，不是独立页面 |

打卡不再放在计算器页。计算器只回答“几点睡/几点起”，入睡页只负责记录，统计只负责回顾——三个 tab 各自闭环。

## 2. 计算器

### 2.1 交互

- 顶部：入睡耗时 `5/10/15/20 分钟`，全局生效。
- 两张手风琴卡，点标题展开/收起；同一时间只展开一张：
  - **你想几点醒来？** 时间轮 → “计算就寝时间”。
  - **你想几点睡觉？** 时间轮 + “用现在的时间” → “计算唤醒时间”，副标题“如果你现在想去睡觉的话”。
- 点击按钮后，正反两面做真正的 3D 翻转（`perspective: 1200rpx` + `preserve-3d` + `backface-visibility`），背面是结果，保留“重新选择”。
- 计算器记忆上次的起床时间、入睡时间、入睡耗时（`storage.getPrefs`）。
- 白天默认入睡时间给 23:00，避免“现在睡到 21:25”的尴尬结果；夜里默认当前时间、点“用现在”可即时回到当下。

### 2.2 算法

- 起床倒推：`W - B - 90 × n`，`n ∈ {5,4,3}`；目标起床取下一次该时刻。
- 入睡推起床：`S + B + 90 × n`，`n ∈ {5,4,3}`；选中的时间已过去超过 30 分钟按次日处理。
- 三个入睡时刻全部已过时，结果卡改为“现在睡还能睡 X”，并列出三个已过时刻。
- 纯函数在 `miniprogram/utils/plan.js`，Node 单测覆盖（`tests/plan.test.js`）。

### 2.3 文案

- 结果只陈述时间与周期，不出现“建议、应该、睡眠质量”。
- 底部固定一句：“每个完整周期约 90 分钟。这里只做时间倒推，不做睡眠质量判断。”

## 3. 视觉系统

Token 全部写在 `miniprogram/app.wxss` 的 `page` 上，页面与组件只引用变量：

- 底色 `#080B14`，卡片实底 `#141B2D`，毛玻璃 `rgba(20,27,45,.65)`。
- 主色 `#818CF8`，深色 `#4F46E5`，月金 `#FDE68A`，薄荷 `#2DD4BF`。
- 文字：月华白 `#F8FAFC`、正文 `#E2E8F0`、次要 `#94A3B8`、弱化 `#64748B`。
- 圆角 16/24/32/48rpx；间距 8/16/24/32/48rpx。
- 动效：`--ease-spring` 弹性按压、`--ease-gentle` 渐显、`flip-in` 结果翻转。
- 字体：标题用 `--font-cn-serif`（宋体栈），正文用系统 sans。

### 3.1 通栏顶部（自定义导航）

- `app.json` 设置 `navigationStyle: "custom"`，去掉固定原生导航条。
- `components/top-bar` 读取 `statusBarHeight` 与胶囊位置，铺一条**透明通栏顶部**，左侧放悬浮玻璃“灵动岛”：睡点 / 计算器（入睡、统计）。
- 顶栏不画整块背景，星轨与月晕透到状态栏；页面滚动时 island 随内容走，不是固定压一条黑条。
- 内容从 island 下方开始，避免“顶上一块、下面一块”的堵闷感。

### 3.2 氛围背景

`components/ambient` 固定全屏：

- 深空径向渐变 + 极慢（180s）星轨 + 9s 呼吸光晕 + 细碎星点。
- 全部 `pointer-events: none`，透明度很低；不支持 `repeating-conic-gradient` 的机型会退化为纯径向渐变。
- 页面内容统一包在 `.page`（`z-index: 1`）里。

### 3.3 玻璃卡片

`.sleep-glass-card`：实底 + 半透 + 1.5rpx 月影描边 + 顶部 1rpx 高光 + `--shadow-moon`。
`backdrop-filter` 不支持时，实底 `--bg-night-surface` 仍可读。

### 3.4 时间轮

`components/time-wheel` 自绘 12 小时循环轮：

- 三列：时 01–12 / 分 00–55 / 上午·下午；对外仍用 24 小时 `"HH:MM"`。
- 时、分各渲染 3 个周期，滚到首尾周期后无感回到中间周期，23 点/55 分不再是终点。
- 未选中 `#94A3B8`（68%），选中月华白 48rpx + 紫色微光；中央带 primary 渐变 + 上下微光描边；冒号 primary。
- 所有颜色有显式 fallback，避免组件样式隔离/变量缺失时整列变黑。
- 使用 `scroll-view` + 130ms 防抖吸附，滚动结束对齐最近行。

## 4. 入睡页

- 顶部日期 + “我几点睡的”。
- 三态：A 未记录 / B 睡梦中 / C 已完成。
  - A：月相大圆钮“入睡”，点击全屏熄灯并显示“晚安”。
  - B：圆钮“记录起床”，下方提供“点错了？撤销本次入睡”（只清会话，不产生记录）。
  - C：圆钮收起，改为入睡/起床/在床时长三项汇总；可撤销。
- 最近 7 天圆点条：已完成为实心分级，进行中为空心光环，今天有外圈高亮。
- 右下角 audio-dock 悬浮钮；播放中变成底部迷你播放器（标题、剩余定时、暂停/展开）。
- 切换 tab、收起抽屉都不中断音频；只有播放条关闭或定时到点才停止。

## 5. 音频与定时

- `components/audio-dock`：悬浮钮 → 迷你播放器 → 底部玻璃抽屉（解锁条、搜索、分类、列表、定时、缓存）。
- 继续使用 `BackgroundAudioManager`（不是 `InnerAudioContext`），锁屏/切 tab 可播；抽屉 `detached` 只解绑监听。
- 定时器是 `utils/audio-timer.js` 模块单例，跨页面存活；到点停止并清除迷你播放器。
- 音频播放时写入 `lastTrackTitle / lastTrackActive`，回到入睡页可恢复迷你播放器状态。
- 解锁：广告与缓存并行，看完广告通常直接本地秒播；缓存可在抽屉里查看占用并清理。
- 收藏：列表右侧星标，本地持久化；分类栏的“收藏”可直接播放收藏列表（不参与云同步）。

### 5.1 统计页

- 120 天横向滚动热力图（7 行、周一对齐、月份标签、今日圈、仅入睡空心格），支持近 30 天/4 个月切换。
- 本周均值、连续天数、事实回顾；云同步状态 + 手动同步。
- “生成月度海报”保存到相册，并作为分享卡片图。
- “清除数据（云端+本机）”：先调 `POST /api/records/erase` 成功后再清本地，避免同步复活。

## 6. 兼容与降级

- `backdrop-filter`、`repeating-conic-gradient`、flex `gap` 在低端安卓/旧 iOS 上可能降级；实底、纯渐变、相邻间距仍成立。
- 原生 `picker-view` 的 `indicator-style` 因基础库版本可能表现不同，选中态仍由自绘 class 保证。
- 熄灯动画是透明度过渡，不做位移，低端机也不掉帧。
