## 2. 计算器

### 2.1 交互

- **单卡双面**，默认「选择起床时间」（Hero 标题「想几点起？」）；卡顶是一个轻量 pill + `⇄`，点击切换「选择入睡时间」（Hero 标题「想几点睡？」），不做传统 segmented control。Hero 标题始终描述**你要选的那个时间**，与胶囊同侧；副标与主按钮描述算出的结果。
- 正面：12h 时间轮 + 共享入睡耗时 `5/10/15/20/30 分钟`（默认 15，仅当前值带小标签底）+ 动态主按钮（`计算我的睡点` / `计算我的起床时间`）。
- 点击后只让计算卡做真正的 3D 翻转（`perspective: 1600rpx` + `preserve-3d` + `backface-visibility`），Hero、脚注、底栏不翻转。
- 结果面：页头与正面**同高**（回显所选时间，字号与问句一致 72rpx；副标在结果态视觉隐藏但保留占位，翻面时整页不位移）；第一推荐大号 + 左侧紫色竖条，其余两行弱化；操作分两行——上行「提醒我入睡/起床 + 换成我想几点睡/起（无框文字）」，下行「‹ 返回 + 去入睡打卡（实底主按钮）」；切换方向并翻回，不刷新页面。
- 计算器只记忆上次的起床时间；入睡时间每次默认跟随真实当前时间，入睡耗时默认 15 分（本次会话内可调整）。
- 入睡模式默认取当前时间（精确到分钟），点“用现在”可即时回到当下；切换模式不会让“预计入睡耗时”行上下跳动。
- 睡眠记录按“醒来日”归属：23:30→次日 07:00 归次日，午休归当天；一天可有多段，主睡眠取最长一段用于连续天数与详情拆分，统计页 Hero/趋势/日历统一看当天总睡眠（各段之和）。
- 结束入睡先弹校准面板：可改入睡/起床时间、预览归入日期；完成态可“再记一段（现在计时）”，也可“补记一段（已发生）”；补记支持选择醒来日并处理跨午夜，每条睡眠段可单独改时间。
- 完成态时间轴按本日睡眠段分段：轨道总长 = 首段入睡 → 末段起床，亮条 = 真正睡着的段，缺口 = 清醒；多段时轨道下补段间说明：间隔 < 90 分钟「N 段 · 中间醒了 M 次（X 分钟）」，≥ 90 分钟「N 段 · 相隔 X」，避免一条直线把「3 段共 26 分钟」读成「连续 30 分钟」。
- 忘记结束超过 24 小时：面板显示只读「入睡（真实打卡日）」并可改「醒来日」（默认入睡次日 + 常用起床时间），入睡时间晚于醒来时间直接报错，不再把两天前的入睡压到昨天。
- 到点提醒采用一次性订阅消息，未配置/拒绝时回落手机日历；不提供“微信常驻状态”，也不以静音后台音频伪造常驻。
- 时间轮下显示**选中时刻**的上下文（今天/明天 + 时段词 + 24h）：起床模式「明天 早晨 07:30 起床」（与倒推共用 `nextWakeAt`）、入睡模式「今天 晚上 22:30 入睡」（与 `wakeTimesForSleep` 共用 `sleepAtOf`，超 30 分钟宽限按次日）；结果时间前缀改用「凌晨/早晨/上午/中午/下午/傍晚/晚上」，不再用「今天/明天」。结果头图标随方向：入睡点=月牙、起床时间=太阳。
- 结果页带时长护栏：主推荐徽标显示「推荐/偏短/不足/充足」，行尾同色提示；主推荐 <7h 或凌晨 1–6 点入睡时给简短睡眠卫生提示，不改变 90 分钟算法。
- 脚注「按 90 分钟周期计算，仅作时间参考」整行可点，打开底部说明层（复用 `styles/sheet.wxss`）：一轮常见 70–120 分钟、平均约 90 分钟；8 小时 = 5.33 个周期；5 个周期 = 7.5 小时；结尾带「不构成医疗建议」。打开时隐藏自定义 tabBar，关闭/页面隐藏恢复。
- Hero 背景图：后台配置多张/分类/默认图；默认图免费并静默缓存，用户更换需看激励视频，到期回退默认。

### 2.2 算法

- 起床倒推：`W - B - 90 × n`，`n ∈ {5,4,3}`；目标起床取下一次该时刻。
- 入睡推起床：`S + B + 90 × n`，`n ∈ {5,4,3}`；选中的时间已过去超过 30 分钟按次日处理。
- 附加档 `n = 6`（9 小时）：作为「充足/补觉」备选只多一行，不参与主推荐；上床时刻已过时不渲染。9 小时标「充足」（成人常见区间上限），不与 5 个周期的「推荐」撞标签。
- 三个入睡时刻全部已过时，结果卡改为“现在睡还能睡 X”，并列出三个已过时刻。
- 纯函数在 `miniprogram/utils/plan.js`，Node 单测覆盖（`tests/plan.test.js`）。

### 2.3 文案

- 结果陈述时间、周期与一般睡眠时长参考；不出现医疗诊断或治疗建议。
- 底部固定一句：“按 90 分钟周期计算，仅作时间参考。”

## 3. 视觉系统

Token 全部写在 `miniprogram/app.wxss` 的 `page` 上，页面与组件只引用变量：

- 底色 `#080B14`，卡片实底 `#141B2D`，毛玻璃 `rgba(20,27,45,.8)`（旧稿写 .65，已按实现校正）。
- 主色 `#818CF8`，浅紫 `#A7A4FF`（`--color-primary-soft`；历史上有 16 处引用但变量缺失，已补齐），深色 `#4F46E5`，月金 `#FDE68A`，薄荷 `#2DD4BF`。
- 文字：月华白 `#F8FAFC`、正文 `#E2E8F0`、次要 `#94A3B8`、弱化 `#7C8799`。
- 表面色：悬浮 tabBar 单独一档 `#0A0E1A`（`--color-tabbar-surface`）。
- Hero 压暗统一为 `--hero-scrim`（0.58 / 0.55 / 0.86）：计算器页与 `hero-backdrop` 组件共用，不再各写一份。
- 圆角 16/24/32/48rpx；间距 8/16/24/32/48rpx。
- 层级表（唯一来源，使用处带 fallback）：`--z-hero 0` / `--z-page 1` / `--z-topbar 30` / `--z-fab 40` / `--z-collapse-mask 85` / `--z-tabbar 90` / `--z-player 100` / `--z-player-host 120` / `--z-dim 150` / `--z-sheet-mask 180` / `--z-sheet 200` / `--z-unlock 300` / `--z-overlay 9999`。注意：自定义 tabBar 渲染在独立 root，页面级 z-index 盖不住它；需要隐藏时由页面调用 `utils/tabbar.hide()`。
- 触控：视觉小于 72–88rpx 的目标用 `::after` 扩命中区（计算器档位、统计海报按钮、入睡页提示条）；`<button>` 的 `::after` 是微信原生边框伪元素，不能用来扩热区。
- 动效：`--ease-spring` 弹性按压、`--ease-gentle` 渐显、`flip-in` 结果翻转。
- 字体：主标题/问题用系统 sans（600），只有“晚安/愿今夜好眠”等诗意文案用宋体。

### 3.1 通栏顶部（自定义导航）

- `app.json` 设置 `navigationStyle: "custom"`，去掉固定原生导航条。
- `components/top-bar` 读取状态栏与胶囊位置，铺一条**透明通栏顶部**；胶囊左侧是一整条玻璃“灵动岛”（不是小胶囊），从左侧安全边距延伸到胶囊前。
- 顶栏本身完全透明，只有 island 有半透玻璃；`position: fixed` 悬浮，页面滚动时内容从岛下方穿过，没有整块固定背景。
- 页面用 `topbar-spacer` 预留高度，避免第一屏被盖住。

### 3.2 氛围背景

`components/ambient` 固定全屏：

- 一层深空径向渐变 + 一层极慢（12s）呼吸月晕，不再叠星轨/星点/多重光斑。
- 全部 `pointer-events: none`，透明度很低；低端机少一层动画，视觉更干净。
- 页面内容统一包在 `.page`（`z-index: 1`）里。

### 3.3 玻璃卡片

`.sleep-glass-card`：实底 + 半透 + 1rpx 月影描边 + `0 12rpx 36rpx rgba(0,0,0,.26)` 轻阴影。
`backdrop-filter` 不支持时，实底 `--bg-night-surface` 仍可读。去掉了顶部高光和选中态紫色描边，减少“每条都发光”的噪声。

### 3.4 时间轮

`components/time-wheel` 自绘 12 小时循环轮：

- 主区两列：时 01–12 / 分 00–59（1 分钟粒度）；右侧窄列只放“上午/下午”文字切换，选中项是柔和底色，不再画两个方块。
- 对外仍用 24 小时 `"HH:MM"`；上午 12 点 = 00:00，下午 12 点 = 12:00。
- 时、分各渲染 2 个周期（分钟列 120 行，含 1 分钟粒度），接近首尾 5 行时切到另一份；目标行数字与当前位置完全相同，视觉无跳变，23 点/59 分仍可连续滚。
- 未选中约 45% 透明蓝灰、选中月华白 78rpx；中央是极轻全宽光带，选中数字保持白色。上午/下午是分段选择，点当前项不会改变时间。
- 所有颜色有显式 fallback；使用 `scroll-view` + 130ms 防抖吸附，滚动结束对齐最近行；计算前调用 `flush()` 强制落定，避免旧值计算。

## 4. 入睡页

- 顶部日期 + “我几点睡的”。
- 三态：A 未记录 / B 睡梦中 / C 已完成。
  - A：月相大圆钮“入睡”，点击全屏熄灯并显示“晚安”。
  - B：圆钮“记录起床”，下方提供“点错了？撤销本次入睡”（只清会话，不产生记录）。
  - C：圆钮收起，改为入睡/起床/在床时长三项汇总；可撤销。
- 最近 7 天圆点条：已完成为实心分级，进行中为空心光环，今天有外圈高亮。
- 右下角 audio-dock 悬浮钮；播放中变成底部迷你播放器（标题、剩余定时、暂停/展开）。
- 切换 tab、收起抽屉都不中断音频；只有播放条关闭或定时到点才停止。

## 5. 音频与定时

- `components/audio-dock`：悬浮钮 → 迷你播放器 → 底部玻璃抽屉（解锁条、搜索、分类、列表、定时、缓存）。
- 继续使用 `BackgroundAudioManager`（不是 `InnerAudioContext`），锁屏/切 tab 可播；抽屉 `detached` 只解绑监听。
- 定时器是 `utils/audio-timer.js` 模块单例，跨页面存活；到点停止并清除迷你播放器。
- 音频播放时写入 `lastTrackTitle / lastTrackActive`，回到入睡页可恢复迷你播放器状态。
- 跨页控制：声音入口仍在入睡页；开始播放后，首页/统计页出现 `now-playing` 迷你条，可暂停/继续/停止或点回入睡页。
- 解锁：广告与缓存并行，看完广告通常直接本地秒播；播放后自动落盘缓存，抽屉里已缓存曲目带暗灰 ✓，点 ✓（或长按）只删该曲，整库缓存随统计页「清除数据」一起清理。
- 收藏：列表右侧星标，本地持久化；分类栏的“收藏”可直接播放收藏列表（不参与云同步）。

### 5.1 统计页

- 首屏 3 列核心指标：平均睡眠（`3h39`，在床口径）/ 平均上床（`23:41`，2026-10-27 由「平均入睡」改名）/ 平均起床（`06:20`）。每列只留「大数字 + 短标签」（2026-10-27 起删掉卡面「一行变化」，与上一段的对比不再占首屏）；点击任一列在下方展开事实说明卡（口径 / 与上一段对比 / 极值与参照，平均睡眠 4 行、上床与起床各 3 行），再点收起。常见 7.5–8 小时的参照陈述同样只放在说明卡里，首屏只留三列数字与一行打卡信息。删除「本周事实」区块、底部口径长句与近 14 天趋势图。
- 打卡日历：周期 `当月 / 3 个月 / 6 个月 / 1 年`。当月 7 列 × 5–6 行，每格 88rpx，格内日号 + 时长；3/6/12 个月改为横向滑动的连续月历，每格 48rpx（长周期最小格），默认停最新月份，提示「左右滑动查看 · 空格点一下可以补记」。4 档色阶（<4h / 4–6h / 6–8h / ≥8h），同一品牌紫**实色**由弱到强（`#5A57C8 → #6C68E8 → #8A90FF → #A5B4FC`，对空格约 3.1/4.1/6.6/9.2 比 1；最高档刻意停在浅紫、不近白，避免被读成空格/高亮；不要用半透明，会被空格吃掉对比），图例为 4 段连成的色阶条 + 下方区间标签，口径「颜色越亮 = 记录时长越长」（只表达时长，不评价好坏）；今天内描边、未来虚线、进行中内描边 + 亮点；点击有选中态与详情卡（日期/上床/起床/时长/分段汇总/按醒来日归档）；详情卡逐段列出时间与时长并带「改 / 删」（2026-10-27：统计页是历史记录唯一的修正入口，入睡页只处理当天）；空白天提供「补记这一天的睡眠」跳转入睡页并预填日期。底部一行「N 天有记录」+ 圆形分享钮 + 淡紫胶囊「近 30 天回顾」。
- 顶部接入 `hero-backdrop`，与计算器/入睡页共用后台背景图与渐隐 scrim；无数据空状态为**单一「3×3 迷你热力格」**（月牙已移除，避免与网格并排被读成两个图标）：格子在柔光中居中，左上首格亮起并带轻微呼吸光，呼应「打一次卡，这里就会长出第一格」；格子 30rpx、描边 0.22 保证 9 格在深底上都可见；CTA 保持「去入睡」。
- “近 30 天回顾”保存到相册，并作为分享卡片图；旁边有独立的页内转发入口。
- 广告位观测：展示位加载成功/失败上报 `ad_show` / `ad_error`，后台概览看填充率与分槽数据。
- 音频解锁观测：激励视频成功上报 `audio_unlock`，跳过/忙碌/加载失败/不可用上报 `audio_unlock_fail`；后台概览看今日/本周成功、失败、加载失败率（排除用户跳过）与原因排行。
- 云备份与清除数据默认收进「数据与备份」折叠区，只露一行同步状态；展开后才出现开关、手动同步、删除云端副本与清除入口。
- “清除数据”：未开启云备份时本地立即清除，并保留云端副本重试入口；已开启时先调 `POST /api/records/erase` 成功后再清本地，失败可只清本机。清除会同时清理解锁、收藏、计算偏好、缓存，弹窗逐项说明；危险入口只保留“会删除什么、不可恢复”，不再重复云备份介绍。
- 关闭云备份后可在同一区域单独“删除云端副本（保留本机）”，走 `cloudOnly`，不写 erasure 水位。

## 6. 兼容与降级

- `backdrop-filter`、flex `gap` 在低端安卓/旧 iOS 上可能降级；实底、纯渐变、相邻间距仍成立。
