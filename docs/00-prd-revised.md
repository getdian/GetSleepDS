## 0. 先看：相对原始 PRD 的 10 处改动

| # | 原方案 | 修订为 | 原因 |
|---|---|---|---|
| 1 | `wx.createInnerAudioContext()` 播放环境音 | `wx.getBackgroundAudioManager()` + `requiredBackgroundModes: ["audio"]` | InnerAudioContext 在锁屏/切后台后停止，睡前场景等于不可用 |
| 2 | 后端调大模型生成"事实回顾" | 服务端模板引擎 + 禁词校验，不接 LLM | 输出完全由数据决定；红线不能交给概率模型，且省延迟、省成本、免 AIGC 审核项 |
| 3 | 示例时间 `23:15 / 00:45 / 02:15` | `23:45 / 01:15 / 02:45`（07:30 起床、15 分钟入睡） | 原示例与"90 分钟周期"不自洽（详见 3.2） |
| 4 | 打卡数据只存本地 | 本地优先 + 可选静默 openid 云备份（默认关闭，统计页显式开启） | 清缓存/换机会丢连续记录；默认关闭保证“数据本地化”，需要备份的用户可主动开启 |
| 5 | 点击播放即弹广告解锁 | 首次播放前解释一次；24h 内不再打扰；无广告位时直接解锁 | 睡前是耐心最低的时刻，弹窗拦截的流失远高于广告收益 |
| 6 | 为订阅去广告做预留 | 不做支付、不做订阅预留；解锁策略由服务端 `unlock.mode` 下发（`rewarded` / `free`） | 小程序内虚拟支付受限，iOS 尤其；未来做会员应走 App 内购，不应留在小程序里 |
| 7 | 首屏直接铺整年空热力图 | 3 个月前的 1 号起（当前 10 月即 7/1），末尾约 3 周为未来占位虚线，不提供范围切换 | 月对齐让月份标签稳定、跨月可读；固定窗口消除切换带来的口径漂移，也不像整年图板那样一眼全是空格 |
| 8 | 环境音只有一张平铺列表 | 分类 + 搜索 + 本地缓存 + Wi-Fi 预加载 | 音频多了找不到；首播等待直接破坏睡前体验 |
| 9 | 配置与音频只能改文件 | 后台管理：配置、COS 上传、分类、看板 | 运营改配置不该改代码，也不该让非技术同事碰 JSON |
| 10 | 只有小程序，外部看不到效果 | H5 交互演示 + 落地页 | 朋友、审核、合作方能直接在浏览器里点一遍 |

## 1. 产品定义

**一句话**：打开即用的睡眠时间计算器 + 一键打卡 + 环境音，全程不需要登录、授权、实名。

**目标用户**：18–32 岁职场新人与学生，作息不规律，晚上会主动查"现在睡还能睡几小时"。

**核心场景（按频次排序）**

1. 睡前 5 分钟打开，看"现在睡还能睡几个周期"，按一下打卡。
2. 早上想起，补记起床时间，看到昨晚睡了多久。
3. 周末翻回顾，看这一周的入睡/起床时间分布。
4. 躺下后放环境音，锁屏，定时关闭。

**明确不做**

- 不做睡眠监测（麦克风/加速度）、不做睡眠质量评分、不做任何健康建议。
- 不做社区、评论、好友关系链。
- 不做登录页、手机号绑定、头像昵称获取。
- 不做浅色模式。

## 3. 计算器页规格

> 2026-10 改版：打卡状态机已移到「入睡」页，本节只描述计算器。

### 3.1 布局

1. 标题「今晚，几点睡？」+ 一行说明。
2. 入睡耗时：`5 / 10 / 15 / 20 分钟`。
3. 手风琴卡 A：「你想几点醒来？」→ 时间轮 → 计算就寝时间。
4. 手风琴卡 B：「你想几点睡觉？」+「如果你现在想去睡觉的话」→ 时间轮 + 用现在的时间 → 计算唤醒时间。
5. 点击按钮后卡片翻转为结果；结果含主推荐、其余周期、重新选择。

### 3.2 倒推算法

- 周期长度固定 90 分钟。
- 目标起床时间 `W`（分钟），入睡耗时 `B`（分钟）。
- 推荐入睡时刻：`W - B - 90 × n`，`n ∈ {5, 4, 3}`。
- 07:30、15 分钟 → **23:45 / 01:15 / 02:45**。
- 若三个时刻全部已过，主结果改为“现在睡还能睡 X”，其余时刻标注已过。

> 原始 PRD 的 `23:15 / 00:45 / 02:15` 与 90 分钟周期对不上，本实现以公式为准。

### 3.3 入睡推起床

- 入睡时间 `S`，起床时刻：`S + B + 90 × n`，`n ∈ {5, 4, 3}`。
- 23:00 + 15 分钟 → 06:45 / 05:15 / 03:45。
- 选中的时间已过去超过 30 分钟，按次日处理。
- 白天默认入睡时间给 23:00，避免“现在睡到 21:25”。

### 3.4 结果与动效

- 点击后卡片内容翻转入场（`rotateY`），不做大幅位移。
- 主时间用宋体大字，周期与时长在下方；其余周期列表显示“今天/明天”与“已过”。
- “重新选择”返回时间轮；结果面可点“X 分钟入睡”切换 5/10/15/20 并自动重算已有结果。

## 4. 回顾页规格

### 4.1 本周概览

- 本周定义：周一 00:00 至今天（本地时区）。
- 三项均值：平均入睡时间、平均起床时间、平均睡眠时长。
- 附加：本周打卡天数、当前连续天数。
- 无数据时展示空状态（文案见 7.2）。

### 4.2 热力图

- 用 `view` + `display: grid`，**不使用 Canvas**。
- 7 行 = 周一到周日，列 = 周；今天之后的日子为未来板位（虚线占位）。
- 范围：3 个月前的 1 号 →（今天 + 21 天）所在周的周日；起点月对齐，不提供切换。
- 分级按单次睡眠时长：

| 等级 | 时长 | 颜色 |
|---|---|---|
| 0 | 无记录 | `rgba(148,163,184,0.10)` |
| 1 | < 6 小时 | `#312E81` |
| 2 | 6–7 小时 | `#4338CA` |
| 3 | 7–8 小时 | `#6366F1` |
| 4 | 8–9 小时 | `#818CF8` |
| 5 | ≥ 9 小时 | `#A5B4FC` |

- 点击格子 toast：`10月17日 · 7 小时 12 分` 或 `10月17日 · 未打卡`。
- 图例：`少 ■ ■ ■ ■ ■ 多`。

### 4.3 事实回顾

- 触发：本周已完成记录 ≥ 3 条，且服务端 `features.summary` 为 true。
- 请求 `POST /api/summary`，前端传最近 14 天的已完成记录；服务端自行切分本周/上周。
- 展示上限 2 句，只陈述数据。
- 卡片副标题固定：`只陈述数据，不做评价`。
- 失败时展示"回顾暂时不可用 + 重试"，不阻塞其他内容。
- 不足 3 条：展示"本周记录满 3 天后可查看回顾"，不展示任何结论。

**允许的句式**

- `本周你记录了 4 次睡眠。`
- `平均 23:52 入睡，07:41 起床，平均 7 小时 12 分。`
- `平均入睡时间比上周晚了 14 分钟。`
- `有 3 天在 0 点后入睡。`
- `与上周持平。`

**禁词**（服务端生成后校验，命中即报错，不返回）

```
建议 应该 必须 注意 尽量 改善 提升 治疗 疾病 诊断 评估 质量 健康
专家 推荐 熬夜 早点睡 少熬夜 伤身 风险 症状 失眠 焦虑 抑郁 医嘱
```

## 5. 环境音抽屉规格（audio-dock）

### 5.1 入口与列表

入睡页右下角悬浮“声音”钮；播放中变成底部迷你播放器。点击展开底部玻璃抽屉：

- 解锁状态条（已解锁/免费/观看视频）；
- 搜索框；
- 分类横滑筛选（分类由音频列表自动去重生成）；
- 音频列表（图标/名称/分类/副标题/缓存态/播放态/收藏星标）；
- 分类含“收藏”，可直接播放收藏列表（本地存储，不参与云同步）；
- 定时关闭与缓存占用；
- 无结果时展示空状态。

当前已接入 1 条 COS 音频，后台可直接上传追加，不需要改页面代码。

### 5.2 解锁状态机

本地键 `audio_unlock_expire`（毫秒时间戳）。

1. `expire > now` → 已解锁，点击直接播放。
2. 未解锁或已过期 → 点击弹底部解锁面板（文案：`观看视频，解锁今晚的环境声音（24小时内有效）`）。
3. 确认 → 若 `unlock.adUnitId` 为空或 `mode !== 'rewarded'`：直接解锁（开发期/未开通流量主）。
4. 否则拉起激励视频；**广告播放的同时开始下载并缓存该条音频**：
   - `res.isEnded === true` → 请求 `POST /api/audio/unlock`，成功写 `expire = 服务端 expireAt`；
   - 未看完 → toast `视频没看完，先不解锁`，不解锁；
   - 加载/播放失败 → 按 `unlock.onAdError`（`grant` / `deny`）处理，默认 `grant`。
5. 服务端不可达：本地按 `now + ttlHours` 解锁，标记未同步；不阻塞用户。

### 5.3 播放与缓存

- 使用 `BackgroundAudioManager`，切 Tab、锁屏继续播放；抽屉收起不停止。
- 单曲循环：`onEnded` 后重新设置 `src`。
- 优先播放本地缓存；缓存失效或播放失败时自动回退网络地址。
- 已解锁时，Wi-Fi 下进入小程序预加载前 2 条；非 Wi-Fi 不自动下载。
- 缓存上限（默认 80MB）与有效期（默认 7 天）由后台配置；每天最多清理一次。
- 组件 `detached` 只解绑监听，不停止播放；关闭声音由播放条“关闭”或定时器完成。
- 定时关闭：30 / 60 / 90 分钟 / 关闭，默认 60 分钟；定时器是跨页面模块单例。
- 配置缓存 10 分钟；后台保存后，重开小程序立即生效。

### 5.4 已知限制（写入验收）

- 后台音频同一时间只能播一路，**不支持多音轨混音**。
- 首次播放必须由用户手势触发，不能自动播放。
- 后台音频会占用微信的音乐播放卡片，审核时可能需要说明用途。
- `定时关闭` 依赖小程序进程内的定时器：锁屏或切后台后 JS 会被挂起，计时可能延后到回到小程序时才触发。前台播放时行为准确。
- 本地缓存受微信文件配额与机型影响，失败时只能回退网络播放，不能保证 100% 命中。
- COS 若开启防盗链，必须放行 `servicewechat.com`，否则音频在小程序内会被拒绝。

## 6. 数据规则

### 6.1 睡眠日

一条记录归属哪一天，以**入睡时间往前推 12 小时**的日期为准：

```
睡眠日 = localDate(bedAt - 12h)
```

- 10-17 23:40 入睡 → 睡眠日 10-17
- 10-18 01:30 入睡 → 睡眠日 10-17
- 10-18 08:00 查看"今天" → 睡眠日 10-17（与昨晚记录对齐）

### 6.2 平均时间

不能直接对 `HH:mm` 求平均（23:50 与 00:10 平均会得到 12:00）。使用**圆均值**：把时刻映射为角度，求 `atan2(Σsin, Σcos)` 再还原为 24 小时制。

### 6.3 时长与缺记录

- `durationMin = round((wakeAt - bedAt) / 60000)`。
- 只有入睡、没有起床的记录不写入 `records`，只在 `pending` 中存在，不参与任何统计。
- 时长上限按 20 小时校验，超出视为脏数据丢弃。
- `0 点后入睡` 定义为入睡时刻落在 `00:00–05:59`。

### 6.4 连续天数

从今天往前数；若今天还没打卡，则从昨天起算，避免白天永远显示 0。

### 6.5 本地存储键

| 键 | 内容 |
|---|---|
| `sleep:records:v1` | `{ [day]: { day, bedAt, wakeAt, durationMin, updatedAt } }` |
| `sleep:pending:v1` | `{ bedAt }` |
| `sleep:config:v1` | `{ fetchedAt, data }` |
| `audio_unlock_expire` | 毫秒时间戳（沿用原始 PRD 键名） |
| `sleep:meta:v1` | `{ lastSyncAt, lastTrackId }` |
| `sleep:deleted:v1` | `{ [day]: 删除时间 }` 墓碑，阻止已撤销记录被云端回填 |
| `sleep:audio-cache:v1` | `{ [url]: { path, size, savedAt } }` 音频落盘索引 |
| `sleep:cache-pruned-at` | 上次清理缓存的时间戳 |
| `sleep:events:v1` | 待上报的轻量事件队列（最多 80 条） |

## 7. 文案与合规

### 7.1 全局

- 不出现"睡眠质量、改善、建议、诊断、治疗、疾病、健康、助眠功效"。
- 环境音页统一叫"环境音 / 白噪音"，不写"助眠音乐""治疗失眠"。
- 回顾页明确标注"只陈述数据，不做评价"。
- 所有数字都用客观描述，不出现"你睡得不好/太晚"。

### 7.2 关键文案

| 场景 | 文案 |
|---|---|
| 首页标题 | 今天几点睡？ |
| 空状态（回顾） | 还没有记录。打一次卡，这里就会长出第一格。 |
| 回顾不足 3 条 | 本周记录满 3 天后可查看回顾 |
| 解锁面板标题 | 解锁环境音 |
| 解锁面板说明 | 观看视频，解锁今晚的环境声音（24小时内有效） |
| 广告未看完 | 视频没看完，先不解锁 |
| 晚安 | 晚安 |

## 8. 验收清单

> 2026-10 改版后的页面级验收以 [改版说明](09-redesign.md#7-验收) 为准；以下保留数据、合规与音频链路的基线项。

- [ ] 冷启动 2 秒内出现计算器页，无授权弹窗、无登录页。
- [ ] 两个时间轮都能滚，选完点击按钮出现翻转结果。
- [ ] 07:30 + 15 分钟 → 23:45 / 01:15 / 02:45；23:00 + 15 分钟 → 06:45 / 05:15 / 03:45。
- [ ] 三个入睡时刻全过时，主结果改为“现在睡还能睡 X”，并标注已过。
- [ ] 入睡打卡 → 熄灯动画 → 按钮变“记录起床”；杀进程重进仍是“记录起床”。
- [ ] 记录起床 → 显示时长 → 再进入睡页仍是“已完成”，可撤销。
- [ ] 入睡页声音入口 → 抽屉 → 收起后迷你播放器仍在，可暂停/展开。
- [ ] 清除数据（云端+本机）成功后记录、会话、缓存全部消失，不会被同步拉回。
- [ ] 记录归属正确的睡眠日（凌晨 1 点打卡算前一天）。
- [ ] 热力图格子数量、周一对齐、颜色分级正确；点击有 tooltip。
- [ ] 平均入睡时间跨午夜正确（23:50 + 00:10 → 00:00）。
- [ ] 本周不足 3 条时不显示回顾；≥3 条时返回 2 句以内客观描述。
- [ ] 回顾文本不含禁词（单测覆盖）。
- [ ] 环境音锁屏后继续播放；定时到点停止；收起抽屉/切 tab 不中断。
- [ ] 分类筛选与关键字搜索可用，无结果有提示。
- [ ] 已解锁且 Wi-Fi 时，进入小程序会预加载前两条；非 Wi-Fi 不自动下载。
- [ ] 解锁时广告与下载并行，广告结束后通常可直接从本地缓存播放。
- [ ] 缓存超限或过期会被清理；缓存文件损坏时自动回退网络地址。
- [ ] 未解锁时点击播放出现解锁面板；解锁后 24h 内不再弹。
- [ ] 无广告位配置时点击播放直接可用。
- [ ] 清空本地存储后，云端记录可回填（开启 sync 时）。
- [ ] 后台保存配置后 `/api/config` 立即变化，小程序重开后生效。
- [ ] 后台可上传音频到 COS、改分类、试听；看板能看到打开/打卡/播放与 14 天趋势。
- [ ] `/` 落地页与 `/demo/` H5 演示可访问；H5 仍为旧版结构，不作为新版验收依据。
