## 0. 先看：相对原始 PRD 的 10 处改动

| # | 原方案 | 修订为 | 原因 |

| 8 | 环境音只有一张平铺列表 | 分类 + 搜索 + 本地缓存 + Wi-Fi 预加载 | 音频多了找不到；首播等待直接破坏睡前体验 |
| 9 | 配置与音频只能改文件 | 后台管理：配置、COS 上传、分类、看板 | 运营改配置不该改代码，也不该让非技术同事碰 JSON |
| 10 | 只有小程序，外部看不到效果 | H5 交互演示 + 落地页 | 朋友、审核、合作方能直接在浏览器里点一遍 |

## 1. 产品定义

**一句话**：打开即用的睡眠时间计算器 + 一键打卡 + 环境音，全程不需要登录、授权、实名。

**目标用户**：18–32 岁职场新人与学生，作息不规律，晚上会主动查"现在睡还能睡几小时"。

**核心场景（按频次排序）**

1. 睡前 5 分钟打开，看"现在睡还能睡几个周期"，按一下打卡。
2. 早上想起，补记起床时间，看到昨晚睡了多久。
3. 周末翻回顾，看这一周的入睡/起床时间分布。
4. 躺下后放环境音，锁屏，定时关闭。

**明确不做**

- 不做睡眠监测（麦克风/加速度）、不做睡眠质量评分、不做任何健康建议。
- 不做社区、评论、好友关系链。
- 不做登录页、手机号绑定、头像昵称获取。
- 不做浅色模式。

## 3. 计算器页规格

> 2026-10 改版：打卡状态机已移到「入睡」页，本节只描述计算器。

### 3.1 布局

1. 标题「今晚，几点睡？」+ 一行说明。
2. 入睡耗时：`5 / 10 / 15 / 20 / 30 分钟`，默认 15 分；仅当前值显示为小标签，其余为纯文字。
3. 手风琴卡 A：「你想几点醒来？」→ 时间轮 → 计算就寝时间；时间轮下显示「今天/明天 上午/下午 HH:MM 起床」的上下文。
4. 手风琴卡 B：「你想几点睡觉？」+「如果你现在想去睡觉的话」→ 时间轮 + 用现在的时间 → 计算唤醒时间。
5. 点击按钮后卡片翻转为结果；结果含主推荐、其余周期、重新选择。

### 3.2 倒推算法

- 周期长度固定 90 分钟。
- 目标起床时间 `W`（分钟），入睡耗时 `B`（分钟）。
- 推荐入睡时刻：`W - B - 90 × n`，`n ∈ {5, 4, 3}`。
- 07:30、15 分钟 → **23:45 / 01:15 / 02:45**。
- 若三个时刻全部已过，主结果改为“现在睡还能睡 X”，其余时刻标注已过。

> 原始 PRD 的 `23:15 / 00:45 / 02:15` 与 90 分钟周期对不上，本实现以公式为准。

### 3.3 入睡推起床

- 入睡时间 `S`，起床时刻：`S + B + 90 × n`，`n ∈ {5, 4, 3}`。
- 23:00 + 15 分钟 → 06:45 / 05:15 / 03:45。
- 选中的时间已过去超过 30 分钟，按次日处理。
- 入睡模式默认取真实当前时间（精确到分钟，如 21:28 → 09:28 下午），不再按白天 23:00 预设。

### 3.4 结果与动效

- 点击后卡片内容翻转入场（`rotateY`），不做大幅位移。
- 主时间用无衬线大字，周期与时长在下方；其余周期列表显示「凌晨/早晨/上午/中午/下午/傍晚/晚上」时段前缀与“已过”，不再用“今天/明天”。
- 结果页带时长护栏：5 个周期（7.5h）标「推荐」；4 个周期（6h）标「偏短」；3 个周期（4.5h）标「不足」。主推荐不足 7h 或入睡时间在 01:00–05:59 时给一句通用睡眠卫生提示（非医疗建议），不改变 90 分钟倒推算法。
- “重新选择”返回时间轮；结果面可点“X 分钟入睡”切换 5/10/15/20/30 并自动重算已有结果。

## 4. 回顾页规格

### 4.1 本周核心指标（首屏 3 列）

- 本周定义：周一 00:00 至今天（本地时区）。
- 首屏只放 3 列，每列「大数字 + 短标签 + 一行变化」：
  1. **平均睡眠**（`3h39`）：当天总睡眠（含午休/间断段）的周均值；副标是与上周的差值（`少 26 分`）。
  2. **平均入睡**（`23:41`）：圆均值；副标是比上周早/晚多少分钟。
  3. **平均起床**（`06:20`）：主睡眠结束时刻的圆均值；副标同上。
- 首屏不再放长段说明：常见 7.5–8 小时的参照陈述只出现在点击后的说明卡里（见 4.3），避免首屏变成文字墙。
- 打卡信息降为一行：`本周记录 2 天 · 连续 2 天`。
- 每列可点击展开最多 3 行说明；再点同一列收起；说明卡默认不展开。
- 无数据时展示空状态（文案见 7.2）。

### 4.2 打卡日历（当月 + 3/6/12 个月）

- 周期切换：`当月 / 3 个月 / 6 个月 / 1 年`，默认当月。
- 当月：7 列（周一起）、5–6 行，每格 88rpx，格内显示日号与紧凑时长（`3.7h`）；左右箭头切月（最早 24 个月，不能切到未来）。
- 3/6/12 个月：横向滑动的连续月历，每格 48rpx（24px，长周期的最小格），格内只显示日号；默认滚到最新月份，提示「左右滑动查看 · 空格点一下可以补记」。
- 分级按**当天总睡眠**，4 档：

| 等级 | 时长 | 颜色 |
|---|---|---|
| 0 | 无记录 | `rgba(255,255,255,0.045)` |
| 1 | < 4 小时 | `#3F3C9E` |
| 2 | 4–6 小时 | `#5B57D6` |
| 3 | 6–8 小时 | `#B4BEFF` |
| 4 | ≥ 8 小时 | `#E0E7FF` |

- 图例固定写「颜色越亮 = 睡得越久」；今天内描边；未来虚线淡显；进行中的今天用内描边 + 亮点。
- 点击格子：选中描边 + 固定详情卡（日期/周几、入睡 → 起床、总时长、夜间与午休拆分、按醒来日归档）。
- 空白天：详情卡显示「这天还没有记录」+ `补记这一天的睡眠` 按钮；点击写入 `meta.manualDay` 后切到入睡页，由入睡页打开补记面板并预填该日期（默认 23:00 → 07:00）。
- 旧的 3 个月横向热力图组件与近 14 天趋势图已移除（趋势信息与日历重叠，运营反馈看不懂）。

### 4.3 指标说明卡（点击展开）

- 触发：点击首屏任一指标；再次点击同一指标收起；固定最多 3 行。
  - 平均睡眠：`本周 2 天平均 3 小时 39 分，含午休与间断段` / `本周平均比常见 7.5–8 小时少 1 小时 30 分`（落在区间内则写 `本周平均在常见 7.5–8 小时内`）/ `最长 6 小时 12 分 · 最短 3 小时 39 分`。
  - 平均入睡：`本周 2 天平均 23:41 入睡` / `比上周早 12 分钟` / `有 2 天在 0 点后入睡 · 按醒来日归档`。
  - 平均起床：`本周 2 天平均 06:20 起床（主睡眠）` / `比上周早 26 分钟` / `这是你记录起床的时刻，不是闹钟`。
- 全部由客户端本地生成，零上传；服务端 `/api/summary` 与 `features.summary` 保留，但统计页不再依赖。
- 文案仍受 7.1 禁词约束；上周无记录时明确写「上周没有记录，暂时无法对比」，不编造差值。

**允许的句式**

- `本周 2 天平均 3 小时 39 分，含午休与间断段`
- `本周平均在常见 7.5–8 小时内`
- `按已记录的 1 天算，补记后会更接近真实`
- `有 2 天在 0 点后入睡 · 按醒来日归档`

**禁词**（客户端模板与服务端生成后都校验，命中即不展示）

```
建议 应该 必须 注意 尽量 改善 提升 治疗 疾病 诊断 评估 质量 健康
专家 推荐 熬夜 早点睡 少熬夜 伤身 风险 症状 失眠 焦虑 抑郁 医嘱
```

## 5. 环境音抽屉规格（audio-dock）

### 5.1 入口与列表

入睡页右下角悬浮“声音”钮；播放中变成底部迷你播放器。点击展开底部玻璃抽屉：

- 解锁状态条（已解锁/免费/观看视频）；
- 搜索框；
- 分类横滑筛选（分类由音频列表自动去重生成）；
- 音频列表（图标/名称/分类/副标题/缓存态/播放态/收藏星标）；
- 分类含“收藏”，可直接播放收藏列表（本地存储，不参与云同步）；
- 定时关闭与缓存占用；
- 无结果时展示空状态。

当前已接入 1 条 COS 音频，后台可直接上传追加，不需要改页面代码。

### 5.2 解锁状态机

本地键 `audio_unlock_expire`（毫秒时间戳）。

1. `expire > now` → 已解锁，点击直接播放。
2. 未解锁或已过期 → 点击弹底部解锁面板（文案：`观看视频，解锁今晚的环境声音（24小时内有效）`）。
3. 确认 → 若 `unlock.adUnitId` 为空或 `mode !== 'rewarded'`：直接解锁（开发期/未开通流量主）。
4. 否则拉起激励视频；**广告播放的同时开始下载并缓存该条音频**：
   - `res.isEnded === true` → 请求 `POST /api/audio/unlock`，成功写 `expire = 服务端 expireAt`；
   - 未看完 → toast `视频没看完，先不解锁`，不解锁；
   - 加载/播放失败 → 按 `unlock.onAdError`（`grant` / `deny`）处理，默认 `grant`。
5. 服务端不可达：本地按 `now + ttlHours` 解锁，标记未同步；不阻塞用户。

### 5.3 播放与缓存

- 使用 `BackgroundAudioManager`，切 Tab、锁屏继续播放；抽屉收起不停止。
- 单曲循环：`onEnded` 后重新设置 `src`。
- 优先播放本地缓存；缓存失效或播放失败时自动回退网络地址。
- 已解锁时，Wi-Fi 下进入小程序预加载前 2 条；非 Wi-Fi 不自动下载。
- 缓存上限（默认 80MB）与有效期（默认 7 天）由后台配置；每天最多清理一次。
- 组件 `detached` 只解绑监听，不停止播放；关闭声音由播放条“关闭”或定时器完成。
- 定时关闭：30 / 60 / 90 分钟 / 关闭，默认关（用户明确选择档位后才起表，不跨会话回忆上次档位）；定时器是跨页面模块单例。
- 配置缓存 10 分钟；后台保存后，重开小程序立即生效。

### 5.4 已知限制（写入验收）

- 后台音频同一时间只能播一路，**不支持多音轨混音**。
- 首次播放必须由用户手势触发，不能自动播放。
- 后台音频会占用微信的音乐播放卡片，审核时可能需要说明用途。
- `定时关闭` 依赖小程序进程内的定时器：锁屏或切后台后 JS 会被挂起，计时可能延后到回到小程序时才触发。前台播放时行为准确。
- 本地缓存受微信文件配额与机型影响，失败时只能回退网络播放，不能保证 100% 命中。
- COS 若开启防盗链，必须放行 `servicewechat.com`，否则音频在小程序内会被拒绝。

## 6. 数据规则

### 6.1 归属日

新记录按“醒来日”归属，一天可有多段（夜间睡眠 + 午休/间断睡眠）：

```
记录日 = localDate(session.endAt)
```

- 10-17 23:40 入睡、10-18 07:30 起床 → 归 10-18
- 10-18 01:30 入睡、10-18 08:00 起床 → 归 10-18
- 10-18 13:00–13:25 午休 → 归 10-18

旧版 v1 记录保留原“入睡日”口径（`dayRule: 'bed-v1'`），不静默重排历史；新记录写 `dayRule: 'wake-v1'`。

### 6.2 平均时间

不能直接对 `HH:mm` 求平均（23:50 与 00:10 平均会得到 12:00）。使用**圆均值**：把时刻映射为角度，求 `atan2(Σsin, Σcos)` 再还原为 24 小时制。

### 6.3 时长与缺记录

- 每段 `durationMin = round((endAt - startAt) / 60000)`；当天 `totalDurationMin` 为各段之和。
- 主睡眠取最长一段（`nightDurationMin`）：连续天数与详情拆分使用主睡眠；统计页 Hero / 日历 / 海报统一使用 `totalDurationMin`（当天总睡眠，含午休/间断段）。
- 只有入睡、没有起床的记录不写入 `records`，只在 `pending` 中存在，不参与任何统计；超过 24 小时不再静默清除，提示手动校准。
- 单段上限按 24 小时校验，单日总睡眠上限 24 小时，超出视为脏数据丢弃。
- `0 点后入睡` 定义为入睡时刻落在 `00:00–05:59`。

### 6.4 连续天数

从今天往前数；若今天还没打卡，则从昨天起算，避免白天永远显示 0。

### 6.5 本地存储键

| 键 | 内容 |
|---|---|
| `sleep:records:v1` | v2：`{ [day]: { day, dayRule, schemaVersion, bedAt, wakeAt, durationMin, nightDurationMin, totalDurationMin, sessions[], updatedAt } }` |
| `sleep:pending:v1` | `{ bedAt, expectedWakeAt, reminderOptIn, id }` |
| `sleep:config:v1` | `{ fetchedAt, data }` |
| `audio_unlock_expire` | 毫秒时间戳（沿用原始 PRD 键名） |
| `sleep:meta:v1` | `{ lastSyncAt, lastTrackId }` |
| `sleep:deleted:v1` | `{ [day]: 删除时间 }` 墓碑，阻止已撤销记录被云端回填 |
| `sleep:audio-cache:v1` | `{ [url]: { path, size, savedAt } }` 音频落盘索引 |
| `sleep:cache-pruned-at` | 上次清理缓存的时间戳 |
| `sleep:events:v1` | 待上报的轻量事件队列（最多 80 条） |

## 7. 文案与合规

### 7.1 全局

- 不出现"睡眠质量、改善、建议、诊断、治疗、疾病、健康、助眠功效"。
- 环境音页统一叫"环境音 / 白噪音"，不写"助眠音乐""治疗失眠"。
- 回顾页明确标注"只陈述数据，不做评价"。
- 所有数字都用客观描述，不出现"你睡得不好/太晚"。

### 7.2 关键文案

| 场景 | 文案 |
|---|---|
| 首页标题 | 今天几点睡？ |
| 空状态（回顾） | 还没有记录。打一次卡，这里就会长出第一格。 |
| 指标空态 | 本周还没有完整记录。打一次卡，这里就会出现 3 个核心数字。 |
| 记录不足 | 按已记录的 1 天算，补记后会更接近真实 |
| 常见区间 | 本周平均在常见 7.5–8 小时内 |
| 上周无记录 | 上周没有记录，暂时无法对比 |
| 解锁面板标题 | 解锁环境音 |
| 解锁面板说明 | 观看视频，解锁今晚的环境声音（24小时内有效） |
| 广告未看完 | 视频没看完，先不解锁 |
