> 用途：最近几轮修复（音频假播放、缓冲重连、熄灯一键结束、提醒重试、统计入口、分享深链）需要真机确认。

## A 音频（睡前核心，先测这组）

- [ ] **A1 假播放已消失**：打开体验版（之前「迷你条显示正在播放但没有声音」的那台手机/场景）→ 迷你条应显示**已暂停**，点按能从原曲续播。
- [ ] **A2 弱网/首次播放**：切 4G 或弱 Wi-Fi → 点一首**没缓存过**的歌 → 应显示「正在连接」，**不得**出现「刚点播放就变成已暂停」；4 秒内应自动出声（最多自动重试 2 次）。
- [ ] **A3 播放中不会突然停**：正常 Wi-Fi 连续播放（含最大的那首 11.5MB）5 分钟 → 不应中途变成「已暂停」。
- [ ] **A4 锁屏回环**：锁屏 3 分钟以上 → 音乐持续循环，回环点听不出明显断层；微信悬浮音符常驻。
- [ ] **A5 来电/微信语音打断**：播放中来电话 → 挂断后音乐**自动恢复**（不是停在那里等你点）。
- [ ] **A6 悬浮 X 停止**：播放中点微信悬浮条的 X → 回到小程序三个页面，右下角仍显示**已暂停**的条/音符，点按能继续播（杀掉微信重进再验一次）。
- [ ] **A7 继续上次**：杀进程重进小程序 → 声音抽屉顶部有「继续上次 · 曲名」→ 点一下接着听（不会自己突然出声）。
- [ ] **A8 收藏连播**：收藏 ≥2 首 → 抽屉切「🔁 收藏连播」→ 一首播完自动下一首（切歌瞬间悬浮音符闪一下属平台行为，可接受）。
- [ ] **A9 删除单曲缓存**：点已缓存曲目右侧的 **⤓**（或长按）→ 确认删除只影响这一首；正在播放的那首会被拒绝（提示先切歌）。

## B 入睡与熄灯

- [ ] **B1 熄灯一键结束（长觉）**：打卡 → 熄灯 → 等超过 5 分钟 → 点「结束入睡」→ **直接落库**，无弹窗。
- [ ] **B2 熄灯一键结束（误触保护）**：打卡后 5 分钟内点「结束入睡」→ 弹「这一觉只有 N 分钟 / 继续睡 / 结束」，点继续睡不打断入睡。
- [ ] **B3 超 24 小时**：构造一觉超 24h（或用以前遗留的 pending）→ 页面标题是「这一觉还没结束」，常驻卡片两个出口：结束并校准 / 丢弃这段；丢弃后统计与云端都没有这条。
- [ ] **B4 停止二次确认**：迷你条停止按钮首点 → 变红提示「再点一次确认停止」，3 秒内不点则取消；确认后条子消失。

## C 提醒

- [ ] **C1 设置 → 收到**：入睡页设一个 2 分钟后的提醒（需先点订阅授权）→ 到点收到「该睡了」；点通知落地到结束面板。
- [ ] **C2 取消与重建**：结果面「已设提醒」再点一次 → 取消成功；同一时刻再设 → 仍能收到（A→B→A 场景）。
- [ ] **C3 按均值定今晚上床点**：统计页有记录（本周有记录时主语为「按本周均值」，本周为空时自动回退为「按最近 7 天均值」）→ 点该行 → 跳到计算器并**直接展示结果面**，时间已预填。

## D 统计

- [ ] **D1 1 年视图**：切「1 年」→ 首次渲染流畅（初始 6 个月）；向左滑到底 → 更早月份**平滑出现、不跳位**。
- [ ] **D2 月历补记入口**：当月视图空格显示轻量「+」，点格子进详情可补记；整屏不再出现 20 多个「补记」文字。
- [ ] **D3 空态文案**：本周无记录时显示「本周打一次卡，这里就会出现 3 个核心数字（下方是本月日历）」。

## E 分享

- [ ] **E1 分享落地一致**：结果面点「分享给朋友」→ 好友打开 → **直接看到与你的结果面相同的推荐**（不是默认 07:30），不弹任何授权。
- [ ] **E2 看板可见**：分享一次后，后台看板「今日分享」+1；趋势图出现金色分享柱；来源排行出现 `...|share`。
